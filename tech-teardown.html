概念 ① · 前端框架

Next.js + React

概念 ⑤ · 機密安全

金鑰，絕對不能上 Git

程式需要「鑰匙」才能連上資料庫。鑰匙分兩種，放錯地方會出大事。

🔓 anon key

權限小、可公開。放前端沒關係，只能做被允許的事。

NEXT_PUBLIC_… · 可進網站

🔑 service key

權限極大、能改整個資料庫。只放本機、絕不進 Git。

只在 scripts/.env · 千萬別外洩
// 實作守則　把 .env 寫進 .gitignore → git 就不會上傳；一旦金鑰貼上網，等於門鎖公開，必須立刻換新。

概念 ⑨ · 真實世界的資料

資料，往往是髒的

YouTube 字幕是「滾動式」格式，還夾雜定位標記。直接用，句子的時間戳就會對不上聲音。

😖 問題

第 2、3 句播放位置整個跑掉，聽到的跟畫面完全不同段。

字幕含 align 標記 · 時間錯位

🛠 解法

改用字幕內每個字的精確時刻，再用文字比對定位到真實秒數。

word-level timestamp + 文字對齊
// 帶走的觀念　寫程式有一大半時間在清理與理解資料，不是寫華麗功能。能把「對不上」變「對得上」，本身就是很值錢的能力。
Data Wrangling · Problem Solving

  • TypeScript　專案變大後省你除錯
